# Mechanical CAD Designs

This repository documents mechanical CAD modelling, assembly design, and prototype-oriented engineering projects developed using computer-aided design tools.

The repository contains selected models, CAD visualisations, and project documentation covering robotic mechanisms, mechanical components, and mobile robotic platforms.

## Software

- SolidWorks
- Autodesk Fusion 360

*Software used may vary between projects.*

## Projects

### 1. Three-Finger Robotic Gripper

Mechanical CAD design of a three-finger gripper assembly, showing the finger arrangement, base structure, and overall mechanical layout.

**Documentation:** [Three-Finger Gripper](projects/three-finger-gripper/README.md)

### 2. Rover Mechanical Design

CAD modelling and assembly visualisation of a rover platform, focusing on its mechanical structure and component arrangement.

**Documentation:** [Rover CAD Design](projects/rover-cad-design/README.md)
